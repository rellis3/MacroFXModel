Range-Level Edge — do levels beat a placebo?

The foundation test, before any macro/z/confidence. When price first tags a 5m Asia-range level (raw session high/low, and today∩yesterday fib confluence), we race a symmetric ±D barrier: does it bounce (revert) or break? The only honest S/R test is vs a placebo — the same level shifted to the wrong price. If real levels don't bounce more than shifted placebos, "price respects the level" is folklore and the levels-time-the-entry premise is dead.
⚠️ Built, not proven. Needs M1 data (Railway). Read the pooled row: if real bounce ≈ placebo bounce (delta ≈ 0) and OOS expectancy ≤ 0 after cost, levels have no standalone edge — stop before adding filters on top.
