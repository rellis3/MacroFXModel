Multi-Spread Sleeve — does a 10Y tenor diversify the validated 2Y sleeve?

Runs the SAME validated mechanism (yield-spread.html's entry/exit/sizing) on a SECOND spread tenor — US-vs-foreign 10Y nominal differential — then asks the harder question: does combining it with the validated 2Y sleeve actually diversify the book, or just relabel the same rate-divergence bet a few days later? Full design: MD files/MULTI_SPREAD_SLEEVE.md.
⚠️ Pre-registered, isolated — not wired into any live signal. Needs live FRED_KEY + M1 (Railway). Real-yield and breakeven differentials are deliberately NOT here — FRED has no clean foreign leg for those, so a "differential" with only a US side isn't a spread. Two bars must both clear before this means anything: Bar A (does 10Y clear the 2Y sleeve's own audit, on its own) and Bar B (does combining the two actually diversify, at EQUAL risk — not just look better because it's 2× the notional).

Equity curve (OOS, additive — the one to trust)

Daily, non-compounded cumulative sum of each book's flat-sized return — what this engine's own fixed-fractional sizing actually produces. Not the compounded/hypothetical view (CAGR below is compounded; this chart deliberately is not, so no single hot stretch looks artificially dominant).

Outcome uncertainty — bootstrap & Monte Carlo

Bootstrap resamples each book's OOS trades WITH replacement 1,000× — the range of total return / Sharpe consistent with this exact sample, and P(profitable) across those resamples. Monte Carlo instead SHUFFLES the same trades' order 1,000× — the drawdown you could have lived through had the identical trades simply arrived in a different sequence (total return is unchanged by reordering; only the PATH is). Neither is a substitute for real out-of-sample validation (already applied above via the IS/OOS split) — both describe uncertainty WITHIN this one sample, not whether the edge generalizes beyond it.

Monthly P&L — combined book (equal risk)

A cheap concentration check: if a handful of months carry the whole result, that's worth knowing before trusting the headline Sharpe. Additive daily returns, not compounded.
