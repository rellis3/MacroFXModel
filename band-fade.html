📏 Band Fade: daily

When price closes outside a volatility band, does it come back to fair value (EMA20)? This page tests that on daily bars across 25 FX pairs and gold, with costs and a true in-sample / out-of-sample split. The intraday versions of this idea are already null on cost (VWAP ±2σ: 0/26 pairs; Keltner on M1; level touches). The daily version had never been run.
The band unit: ex-ante EWMA σ, scaled so ±2 is a 2-sd stretch for a random walk on every instrument. Keltner (ATR) and Bollinger (σ of the window) are reported next to it as context. Pre-registration: MD files/BAND_FADE_DAILY.md. Read-only research: feeds no signal, bot or order.
