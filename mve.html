📚 Book layer (Phase 7): are the spread sleeves really a dollar bet?
Takes the validated 2Y yield-spread sleeve and the 10Y multi-spread sleeve (config 2.0 / 126, frozen), maps their daily positions into currency space (8 currencies from the 7 USD majors), finds the shared currency factors (rolling 120-day PCA, K by a noise band), and runs the factor-neutral version of the same book. If the OOS edge survives neutralising, it's a genuine rate-spread relative-value edge. If it collapses, the sleeves were mostly a dollar bet. Also shows the currency PCA residual loop (education test #1) as an information-only shadow. Pre-registered in MD files/MVE_BOOK_FACTOR_AUDIT.md. Deployed server only (FRED + M1). The first run takes a few minutes; the result is cached for 6h.
