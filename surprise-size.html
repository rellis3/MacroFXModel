The question

When a data release misses consensus by more than usual, does the next 30 minutes, 2 hours or the rest of the session run wider than the forecast already expected?
Pooled over 8 economies, ForexFactory history 2016-01 to 2025-04, release windows only. Size = |actual − consensus| divided by that series' own recent surprise sd (point in time). The comparison is big against small surprises of the SAME series, after the production range forecast, the event multiplier, the window's usual size at that clock time and the hour before the release. Range only: nothing here says which way price goes.
