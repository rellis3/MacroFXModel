Forward-Track — the confirmed fade, proven forward

The Pooled VuManChu Fade cleared the honest bar out-of-sample — but a backtest is still in-sample to the researcher. This is the only test a backtest can't fake: a live, post-research record. Each refresh re-scans every instrument's just-completed sessions and appends the confirmed fade signals (WT+VWAP, the same detectSessionSignals the validated backtest uses — never a copy) with their realised outcome. The FORWARD block accumulates from the tracking-start date; the baseline block is the pre-tracking backtest on the same instruments. The tell: if forward expectancy tracks the baseline, the edge is real; if it decays toward zero, it was overfit. Refresh is safe to run any time — it backfills from the last logged date, so weekly clicks capture everything. The log persists across redeploys (CF KV).
