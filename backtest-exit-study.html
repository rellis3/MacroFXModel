Backtest exit study — would a different exit bank more?

Replays each trade's real M1 path under alternative exit rules, entry held fixed. The bot's fixed ~2R (often >3R) target hits 1-in-7 and round-trips; this tests closer targets, a trailing stop, a breakeven move and a time-stop against the actual exit. ← Dashboard
How to read it. Every rule is scored in R (risk = |entry−SL|) on the SAME trades, so they're directly comparable; gross R, since cost is ~equal across rules. If a rule's total/expectancy beats actual by a real margin, it's a candidate exit change — to validate OOS, not ship. EXPLORATORY: 279 trades, one ~2-month window; barrier ties resolve adverse-first (conservative). This is about exits — the entry edge is a separate, harder problem (see the entry analysis).
