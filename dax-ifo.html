Both files use the timing, direction and costs selected above (costs start on: financing and the bid/ask spread both on; commission is zero on a spread-only CFD).

Toolkit file: C.OG's format, Date,Return %,MAE %, one row per monthly position (entry date, net % return, worst point ≤ 0 with that trade's costs taken off, two decimals). The worst point of a whole month is counted as if it fell in one day, so a prop firm's daily-loss rule is tested conservatively. Journal file: the import template's 13 columns, the position at 1× the account. Compounded: Return % = the trade's % move. Not compounded: the position stays at the starting balance, so each trade becomes a smaller % of the account as it grows (larger after losses). If a fixed-size position loses the whole starting balance, the file ends at that trade. MAE/MFE are positive sizes; Risk % is a fixed 1% of the position (there is no stop). Times are UK, entry and exit at the 16:30 cash close. Tags: long/short, flip, lookahead on timing A; Notes carry the IFO reading.
