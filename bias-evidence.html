Every verdict, with the checks behind it

Each study cell runs through the same evidence pack: a 95% interval from a date-block bootstrap, the same test on shuffled signals (placebo), a planted edge of the useful size added to the real data to see if the test can find it, splits by half, instrument and year, the result with the biggest 1% of rows removed, costs where they apply, and a look-ahead canary (tomorrow deliberately leaked in, which must move the result). The pack's label says which kind of null it is; the prereg gate still sets the formal verdict, and the two can differ (the pack is a cross-check, not the gate).

UNDERPOWERED The planted edge was found under 80% of the time, so "no effect" is not shown. Means "not proven", not "dead".
FLAT The test could see a planted edge, and the interval rules out the useful size. The strongest kind of null.
WRONG SIGN There is an effect, and it runs the opposite way to the claim.
SMALL BUT REAL Above zero, but the interval stays below the useful bar.
INCONCLUSIVE The interval holds both zero and the useful size.
REAL / GONE NET / UNSTABLE Interval clears zero; then costs or a half that disagrees can still take it away.
