FX/Gold Vol-Carry Backtester · CME CVOL variance risk premium (VRP)

Tests whether options-implied volatility (CME CVOL for FX/gold, CBOE VXN for NQ), compared against this platform's own realized-vol math, is useful as a GATE on the existing fade/follow exhaustion-band strategy — versus always-fade and always-follow at the same band, IS/OOS, with real costs. Built on resolveHonestDay (honestForecastEngine.js) and js/impliedVolCore.js — no new fill logic, no new leg.

What this is, and isn't. This is a spot-only strategy test — no FX options or variance swaps are tradable on this platform, so VRP (implied − realized vol) is used purely as a regime signal gating an already-tradable spot band strategy, never as a literal "sell implied variance" payoff. A synthetic variance-swap P&L would be a different, more optimistic-looking test that this page deliberately does not run.

Two independent implied-vol sources, both static snapshots, not live feeds. CME CVOL covers EURUSD, GBPUSD, USDJPY, AUDUSD, USDCAD, USDCHF, GOLD (XAUUSD) — no crosses, no NZDUSD, no indices. CBOE (GVZ/VXN) supplies the only implied-vol source for NQ (VXN, since CME CVOL has no index coverage), and a second, independent read on GOLD (GVZ) shown as a cross-check against CVOL's own gold read — not a second trading arm, just a correlation + overlay to see whether the two providers agree. Coverage loads with the first run. Refreshing needs a fresh export re-run through scripts/convertCmeCvol.py / scripts/convertCboeVolContext.py.

vrp = the VRP-gated selector (rich → fade the band, cheap → follow it, neutral → flat/no trade). alwaysFade / alwaysFollow = the same band, every eligible day, no VRP gate — the named benchmarks. The number that matters is vrp vs the better of the two baselines on OOS Sharpe, at a non-trivial OOS trade count (≥30). Costs and a true later-period OOS split are applied throughout; the "flat" days are the hypothesis under test, not a fallback — if VRP has no information, the gate should just look like a trade-count-reduced version of one of the baselines, not a better one.
