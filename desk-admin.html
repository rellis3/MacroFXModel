What the desk login can see

Every tab, link, widget, ticker segment and panel of the Desk Terminal is a switch. Anyone signed in with the desk password sees only what is switched on here. You, signed in with the main password, always see everything. The desk login is an education tool and a macro dashboard, so everything is shown except four things, each row says which:

trade reads as a trade instruction (trade watch, playbooks, best pairs, entry / stop / target / size lines, the Trader's read, the hedge finder). cost costs money (Research, Ask the desk, paid model buttons). internal your own tooling (Info map, Desk Office, Desk Run, Access, alerts, the data-quality chip). P&L real or scored P&L: the desk's record. Those four are off by default; everything else is shown. Links out to other pages are locked off (they would bounce a desk login to the main login).
