QMR Tearsheet

Standard results card for the NQ-QMR chassis, in the same field set used by the external reference tearsheet so the two are directly comparable. Every metric comes from js/metricsCore.js — one definition of Sharpe/Sortino/drawdown across the whole repo. Costs are netted before leverage; MAE is read off the real intra-trade path, never approximated from the close.

Defaults are per-instrument — gold trades far smaller % ranges than the equity indices, so it carries its own stop/target/range scale. Changing instrument reloads that instrument's defaults; edit any field and re-run to explore sensitivity.
