# C.OG inbox

Drop C.OG messages you want kept here: one file per message or thread.

- Pasted text: `YYYY-MM-DD-<channel>-<slug>.md`, with the message exactly as posted and who asked what.
- Screenshot: `YYYY-MM-DD-<channel>-<slug>.png`.

Then ask Claude to "process the cog inbox". The `research-director` skill (`references/cog-inbox.md`) files each one
as a verbatim snippet in `education/cog-snippets.md`, adds his phrasing to the question-style reference, turns any
question he poses into an agenda card, and moves the file to `processed/`.

Only add what you choose to keep. Nothing here is scraped from Discord.
