🃏 Trade Cards model …UNCALIBRATED PRIOR

One card per pair: live chart, nearest zone, pip countdown, confidence, and the TP/SL the backtest is actually graded on — plus every other qualifying zone that session, listed below the chart. List view: upcoming-trades.html
TP/SL convention. The Telegram alert and the raw decide() call never print a price for stop/target — they only score direction + confidence. But every backtest number in this system (FIT_FINDINGS.md, the walk-forward fit, the win-rates you've seen) is graded on the SAME triple-barrier rule: TP = 0.5σ, SL = 0.75σ (daily σ, checked intrabar, SL first). Lines below use that exact rule — it's not a new invention, it's making the existing grading rule visible. Confidence is modelV1 (FX majors) or the v0 prior (everything else) — calibrated but weakly selective; see upcoming-trades.html's banner for the full caveat. This is an alert board, not an execution system — you place every trade yourself.

How often does the zone change? Most of the map (pivots, prior hi/lo, fib clusters, round numbers) is built from the last completed daily bar — it only moves once per session (see each card's as-of date). Today's developing high/low updates continuously. A card's zone gets a NEW badge for one refresh when its nearest zone changes.

Asia/Monday zones are confluence-only — the raw fib ladder (every rung of today's session range) is not shown; only today's Asia ladder agreeing with yesterday's, or this week's Monday agreeing with last week's, earns a zone (2-pip FX threshold, tighter agreement scores higher). Monday confluence scores higher than Asia — a weekly repeat is rarer and reacts more than a daily one. Full detail: upcoming-trades.html.
