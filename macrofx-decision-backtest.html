MacroFX Decision Engine · the assembled system

The v1 backtester built only the skeleton — levels → zones, trading every zone every day. This is the rest of the picture the 20-doc spec describes: a monitored decision process on top of the same zones. Per session it reads a market state (trend-strength + trend-day-ness + regime + vol) into a trendiness S that directs each zone — follow a break when S is high, fade to fair value when low, stand aside in between. A confidence gate (independent-evidence count + state alignment + location) fires only high-conviction trades, so the book is selective. Trade management (partial at +1R → break-even → trail → time-exit) works the tail. It runs head-to-head vs the v1 naked skeleton on the same split — the question is whether the decision + confidence + management layers change the result. No verdict pre-loaded.
