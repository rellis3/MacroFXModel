What has been done in the repo · October 2026

Every study run in these sessions: the question, how it was tested, what came out, and where it lives

Each study follows the same protocol: the question and the exact test are written down and pushed before any result is computed (the pre-registration), the run uses data only up to the 2026-08-21 lockbox, and the answer is one of four words: VALIDATED (passed the registered bar), NULL (the effect is ruled out), UNDERPOWERED (couldn't tell either way with this much data) or CONTEXT (a description, not a prediction). The verdicts and numbers below are read live from the Evidence Book (js/deskEvidence.js), so they stay current if anything is re-run.
