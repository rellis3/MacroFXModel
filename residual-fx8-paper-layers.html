The base book was chosen on this same 2016–2026 history, so every number here is in-sample. The layer rules were fixed in scripts/residual-fx8-paper-layers/layers.py before any variant was run. Use this page to see what each paper's idea does to the book, not as proof of an edge. The only test on new data is the forward record.

Strategy

Base: 8 currencies. Each currency's return minus the basket average; a 120-day PCA removes K = 2 common factors (dollar, risk); the cumulative residual path is z-scored. Enter a currency when |z| ≥ 1.5 (fade it), exit when z crosses back through 0. Inverse-vol weights, factor- and basket-neutral, scaled to gross 1, house spread costs. "+carry" adds the 3-month interest differential the book earns or pays.
