One VaR Number, Broken Into Its Parts

Total portfolio VaR tells a risk manager how much could be lost. It says nothing about which position — or which underlying risk factor — is actually driving that number. This deck walks through the machinery that answers the second question additively: every slice, summed, equals the whole.

Section 2

Marginal VaR — a sensitivity, not yet an attribution

Assuming normal returns
VaR_p
=
z_p · σ_p,   σ_p = √(w′Σw)
Marginal VaR_i
=
∂VaR_p/∂w_i = z_p · (Σw)_i / σ_p
Marginal VaR answers "if I added one more dollar to position i, how much would total VaR rise?" — a local sensitivity, holding every other position fixed. It does NOT yet tell you how much of today's VaR position i already caused.
📐

A simplification, stated up front

This closed form needs normal (or elliptical) returns. The sibling Extreme Value Theory lesson exists for exactly the fat-tailed cases where it stops being a good approximation.

🔎

(Σw)_i is position i's total covariance with the whole book

Row i of Σ dotted with the full weight vector — it captures both position i's own volatility AND how it co-moves with everything else.

Section 3

Component VaR — Euler's theorem makes it exact

The key fact: VaR_p is homogeneous of degree 1
Scale every position by λ
→
VaR_p scales by exactly λ, too
Euler's theorem
⟹
Σ w_i · MarginalVaR_i = VaR_p, exactly
Component VaR_i = w_i × Marginal VaR_i. Sum every position's Component VaR and you get total portfolio VaR back — not approximately, algebraically exact. This is the practically crucial result: a clean, additive attribution instead of a vague sensitivity.
A Component VaR can be negative

If a position's exposure and its Marginal VaR have opposite signs, it's a genuine diversifier — removing it would INCREASE total portfolio VaR.

Section 5

Factor VaR — the same logic, one level up

A linear factor model
r = Bf + ε
→
x = B′w — the portfolio's net exposure to each factor
σ_p² = x′Ωx (systematic)
+
w′Dw (specific)
Same Euler mechanism, applied to x instead of w: Factor Component VaR_j = x_j × z_p(Ωx)_j/σ_p. Summing all k factor components plus one specific-risk bucket reproduces total VaR exactly — same architecture as commercial Barra-style multi-factor models (sibling lesson), built here from first principles.
🧭

"Which macro theme?" not "which position?"

A 40-line FX book might reduce to 4-5 real factor exposures — USD-rate, EM-FX, carry. Factor VaR answers the question a portfolio manager usually cares about most.

🎲

Specific risk is a real, honest bucket

Factors never explain 100% of risk. The leftover idiosyncratic variance gets its own component — not split further, since it has no shared driver to attribute it to.

Section 7

How practitioners actually use this

📊

Risk budgeting

Allocate a total VaR budget across strategies, then monitor each one's live Component VaR share against its budgeted slice.

🎯

Targeted hedging

Component VaR points at exactly which position or factor to trim — not an across-the-board de-risking that cuts positions barely contributing at all.

🔀

Marginal VaR ≠ Incremental VaR

Marginal VaR is an infinitesimal slope. Incremental VaR is the real VaR change from adding/removing a WHOLE position (re-run the calc). They agree closely only for small positions.

🧭

Factor VaR for macro books

Reduces a long position list down to the handful of macro themes a portfolio manager actually reasons about day to day.

Section 8

Where this clean result quietly breaks down

📉

Needs normal (or elliptical) returns

Under genuine fat tails, VaR is no longer a clean multiple of σ_p — Marginal/Component VaR must be estimated by simulation instead of read off a formula.

🧩

CVaR has a similar Euler property — not the identical formula

Expected Shortfall is also homogeneous of degree 1, so an analogous decomposition exists (Tasche, 1999) — but the exact algebra differs from VaR's.

🎭

Factor VaR is only as good as B and Ω

Stale loadings, misspecified factors, or a non-diagonal "specific" covariance all quietly misattribute risk while the arithmetic still looks exact.

🌊

Σ is estimated, not known

Calm-period correlations can shift sharply in stress — this category's own CoVaR lesson is built around exactly that worry.

Section 9

Check yourself

Nothing is scored beyond this device. The explanation is the useful part.

Question 1

What does Marginal VaR_i measure?

It's a local sensitivity — ∂VaR_p/∂w_i. Multiplying by w_i (Component VaR) is what turns it into an attribution.
Question 2

Why do Component VaRs sum EXACTLY to total portfolio VaR?

Scaling every position by λ scales VaR_p by exactly λ — that homogeneity is what triggers Euler's exact identity.
Question 3

Could a position have a negative Component VaR?

Negative correlation with the rest of the book can make a position's Marginal VaR negative — a real, useful signal, not an error.
Question 4

In r = Bf + ε, what is x = B′w?

x is what the same Euler logic gets applied to for the factor-level decomposition, in place of w.
Question 5

Why does the closed-form Marginal/Component VaR formula break down under genuinely fat-tailed returns?

Under real fat tails, marginal/component contributions must be estimated by simulation instead of read off a formula.
Question 6

What's the difference between Marginal VaR and Incremental VaR?

For a large trade, the true incremental effect can be meaningfully non-linear — Marginal VaR's local slope is a poor substitute for re-running the calculation.
Section 10

What to carry forward

01

Marginal VaR is a per-unit sensitivity: z_p(Σw)_i/σ_p. Component VaR (w_i × Marginal VaR_i) turns it into a full, exact attribution.

02

Euler's homogeneous function theorem is why the components sum EXACTLY to total portfolio VaR — no residual, no approximation, under the normal-returns assumption.

03

Factor VaR applies the identical logic to x = B′w instead of w — attributing risk across a handful of common factors plus one honest specific-risk bucket.

04

A Component VaR can be negative — a real diversifier, not an error. And the clean closed form depends on normal/elliptical returns and a well-specified factor model; both are checkable assumptions, not guarantees.

What this now lets you do

Take a portfolio's weights and covariance matrix, and answer "which position — or which risk factor — is actually driving our VaR, and by exactly how much" with numbers that add up to the total, not just a ranked guess.
