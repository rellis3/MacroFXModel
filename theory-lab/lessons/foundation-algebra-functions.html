Algebra & Functions Refresher

Rearranging equations, and what a "function" actually is — the two habits of mind every later formula in this curriculum quietly assumes you already have.

CONCEPT — not built or tested in this repo ~14 min read Prereqs: none
TL;DR
  • An equation stays true as long as you do the same thing to both sides — add, subtract, multiply, divide, take a root, apply a log — and "solving for \(x\)" just means repeating that until \(x\) is alone on one side.
  • A function is an input→output machine: one input always produces exactly one output. \(f(x)=x^2\) is a rule, not a specific number — you only get a number once you plug one in.
  • Domain is the set of inputs a function accepts without breaking (dividing by zero, square-rooting a negative); range is the set of outputs it can actually produce.
  • A straight line \(y=mx+c\) has constant slope \(m\) (rise over run) and intercept \(c\) (where it crosses the vertical axis); a quadratic \(y=ax^2+bx+c\) curves, and the sign of \(a\) decides whether it curves up (holds water, "convex") or down (sheds water, "concave").
  • Composition \((f\circ g)(x) = f(g(x))\) chains two machines — feed \(g\)'s output straight into \(f\); an inverse \(f^{-1}\) is the machine that undoes \(f\) exactly, so \(f^{-1}(f(x))=x\).
  • The worked example rearranges the compound-interest formula \(FV=P(1+r)^n\) to solve for the rate \(r\) — the exact same "isolate the variable" moves used later in this curriculum to solve for volatility, position size, or any other unknown buried inside a bigger formula.
Section 01

Why this matters

Every later lesson in this curriculum hands you a formula and expects two things: that you can read it as a function (an input→output rule, not a single fixed number), and that you can rearrange it to solve for whichever piece you actually need. A volatility formula might give you \(\sigma\) from a price series, but a risk-sizing question asks the reverse: "given a target \(\sigma\), what position size do I need?" That's the same algebraic move — isolate the variable you want — applied to a different formula. If rearranging an equation, or reading what "domain," "slope," or "curving up" mean on a graph, ever feels shaky, that shakiness will show up silently in every later lesson that assumes it. This page exists to make those moves automatic before anything else is built on top of them.

💡
Plain-English intuition

An equation is a balance scale; a function is a machine

Think of an equation like \(2x + 3 = 11\) as a balance scale that's currently level. Both sides weigh the same. If you want to know what \(x\) is, you're allowed to do anything you like to the scale — as long as you do the exact same thing to both pans at once, it stays level. Subtract 3 from both sides: \(2x = 8\). Divide both sides by 2: \(x = 4\). Nothing magic happened; you just kept the scale balanced while peeling away everything that wasn't \(x\).

A function is a completely different kind of object: not a balanced statement, but a machine. You feed it an input, it does something fixed and repeatable to that input, and it hands back an output. \(f(x) = x^2\) is the "square it" machine — feed in 3, get back 9; feed in \(-3\), also get back 9 (the machine doesn't care about the sign, only the square). The letter \(x\) inside \(f(x)\) is not a specific number waiting to be solved for, the way it is in an equation — it's a placeholder for whatever you're about to feed the machine. Confusing these two ideas — treating a function like it's an equation to "solve," or treating an equation like it's a machine that already has an answer baked in — is one of the most common early stumbling blocks, and it's worth being explicit about the difference before moving on.

Section 02

The math, step by step

Manipulating expressions and equations

Three moves cover almost everything you'll need in this curriculum: expanding (multiplying out brackets), factoring (the reverse — pulling a common piece back out into brackets), and rearranging (doing the same operation to both sides of an equation to isolate a variable).

\[ \underbrace{a(b+c) = ab + ac}_{\text{expand}} \qquad\qquad \underbrace{ab + ac = a(b+c)}_{\text{factor}} \]
a(b+c)a factored expression — a common term \(a\) multiplying a bracket
ab + acthe same expression expanded — the bracket multiplied out

Rearranging an equation is repeated application of one rule: whatever you do to one side, you must do to the other, in the same order it would take to undo it. To isolate \(x\) in \(2x + 3 = 11\): subtract 3 from both sides (\(2x = 8\)), then divide both sides by 2 (\(x = 4\)). The moves "undo" the operations that were done to \(x\), in reverse order — \(x\) was multiplied by 2 and then had 3 added, so you subtract 3 first, then divide by 2, peeling the layers off from the outside in.

🧒 Explain like I'm 5

Picture a seesaw sitting perfectly level. If you take a brick off one side, it tips — unless you take the exact same brick off the other side too. That's the whole rule. "Solving for x" just means removing stuff from both sides, evenly, until x is the only thing left sitting on its own.

Linear equation

\(mx + c = y\) — one power of \(x\), a straight-line relationship. Rearranging always isolates \(x\) in one or two moves.

Quadratic equation

\(ax^2+bx+c=0\) — a squared term makes \(x\) appear twice, so isolating it usually needs factoring or the quadratic formula, not a single division.

What a function actually is

A function \(f\) is a rule that assigns exactly one output to every input it accepts. Write \(f(x) = x^2 + 1\): this says "whatever you feed in as \(x\), square it and add 1." Feeding in the number 3 gives \(f(3) = 3^2+1 = 10\). The letter \(x\) is a placeholder, not a fixed unknown to be solved for — that's the key difference from an equation.

\[ f(x) = x^2 + 1 \qquad\Rightarrow\qquad f(3) = 3^2+1 = 10,\quad f(-1)=(-1)^2+1=2 \]
fthe name of the function — the machine itself
xthe input placeholder — whatever gets fed in
f(x)"apply the machine \(f\) to input \(x\)" — the resulting output

The rule "exactly one output per input" is what makes something a function and not just any old relationship between two quantities. \(y^2 = x\) is not a function of \(x\) on its own, because \(x=4\) gives two valid \(y\) values (\(+2\) and \(-2\)) — one input, two outputs, which breaks the definition. \(y = \sqrt{x}\) (taking only the positive root by convention) fixes that and is a genuine function.

🧒 Explain like I'm 5

A function is a vending machine. You press "3", it always gives you back exactly one thing — say, 9 (because this machine squares whatever number you press). It's not asking you a question you need to answer; it's just sitting there, ready to spit out an output the moment you feed it an input.

And a machine that sometimes gives you two different snacks for the same button press is broken — that's why \(y^2=x\) doesn't count as a real function, but \(y=\sqrt{x}\) does.

Domain and range

The domain of a function is every input it's allowed to accept without breaking — without dividing by zero, without taking the square root of a negative number (at least while staying in real numbers), and so on. The range is every output the function can actually produce once you feed it every allowed input.

🚫

\(f(x) = \dfrac{1}{x}\)

Domain: every real number except \(x=0\) (division by zero is undefined). Range: every real number except 0 (the machine can never output exactly zero).

✅

\(f(x) = \sqrt{x}\)

Domain: \(x \ge 0\) only (no real square root of a negative number). Range: \(f(x) \ge 0\) — the output is never negative.

♾️

\(f(x) = x^2\)

Domain: every real number (squaring never breaks). Range: \(f(x) \ge 0\) only — a square is never negative, so negative outputs are simply impossible.

🧒 Explain like I'm 5

Domain is "what's this machine allowed to eat." Some machines break if you feed them the wrong thing — try to divide by zero and the whole thing jams. Range is "what can this machine actually spit out." A machine that squares numbers can never spit out a negative one, no matter what you feed it — that's just not a shape the output can take.

Linear, quadratic, and polynomial functions

A linear function has the form \(y = mx + c\): a constant slope \(m\) (how much \(y\) changes for every 1-unit increase in \(x\) — "rise over run") and an intercept \(c\) (the value of \(y\) when \(x=0\), i.e. where the line crosses the vertical axis). Its graph is a perfectly straight line — the slope never changes.

\[ y = mx + c \qquad m = \frac{\Delta y}{\Delta x} = \frac{y_2-y_1}{x_2-x_1} \]
mthe slope — how steeply \(y\) rises (or falls) per unit of \(x\)
cthe intercept — where the line crosses \(x=0\)
Δy/Δx"change in y over change in x" — slope computed from any two points on the line
🧒 Explain like I'm 5

A straight line is just "start somewhere, then go up (or down) by the same amount every single step." \(c\) is where you start, at \(x=0\). \(m\) is the step size — how much \(y\) changes each time \(x\) moves by 1. That step size never changes, and that's the entire definition of "linear."

A quadratic function, \(y = ax^2+bx+c\), has a squared term, so its graph is a curve (a parabola), not a straight line — its slope keeps changing as \(x\) changes. A polynomial is the general family both belong to: a sum of terms like \(a_n x^n\), where \(n\) is a non-negative whole number — a linear function is a degree-1 polynomial, a quadratic is degree-2, and so on to any higher power.

🧒 Explain like I'm 5

A quadratic is what happens the moment the step size stops being constant — it grows (or shrinks) as \(x\) moves, which is exactly why the graph bends instead of staying straight. "Polynomial" is just the family name for any formula built from \(x\), \(x^2\), \(x^3\)... added together. "Degree" simply means the highest power in the mix — \(x\) alone is degree 1, \(x^2\) is degree 2, and so on.

Reading a graph: slope, intercept, concavity

Three visual ideas recur constantly in later lessons, and they're worth naming precisely now, in the simplest possible setting, before they show up wearing more complicated notation.

1

Slope — the direction and steepness

A positive slope means the graph rises left-to-right; negative means it falls. A steeper line has a slope further from zero. A slope of exactly zero is a flat horizontal line — no change at all.

2

Intercept — where it crosses the axis

The \(y\)-intercept is the value of the function when \(x=0\). On a straight line \(y=mx+c\), that's exactly \(c\) — no computation needed, it's read straight off the formula.

3

Concavity — "curving up" vs. "curving down"

A curve that bends upward like the inside of a bowl (its slope is itself increasing as \(x\) increases) is called convex. A curve that bends downward like an upside-down bowl (its slope is decreasing) is concave. For \(y=ax^2\), the sign of \(a\) decides which: \(a>0\) curves up (convex, "holds water"), \(a<0\) curves down (concave, "sheds water").

Why this is worth remembering now: "convexity" comes back later in this curriculum in a much more consequential form — it's the entire reason an option's payoff and a portfolio's risk profile can bend in your favor. Every one of those later, richer discussions reduces, at its core, to this same picture: is the curve bending up, or down?
🧒 Explain like I'm 5

Slope is just "how steep is this hill, and which way does it go" — uphill is positive, downhill is negative, flat ground is zero. Concavity is whether the hill is shaped like a bowl (curves up, would hold water if it rained) or a dome (curves down, water rolls straight off). That's genuinely the whole idea — "convexity," which shows up a lot later in this course wearing fancier clothes, is this exact same bowl-vs-dome picture.

Function composition

Composition chains two functions together: feed an input into the inner function, then feed its output straight into the outer function as input. Written \((f \circ g)(x)\), read "\(f\) composed with \(g\)," or equivalently \(f(g(x))\).

\[ f(x) = x^2, \quad g(x) = x+1 \qquad\Rightarrow\qquad (f\circ g)(x) = f(g(x)) = (x+1)^2 \]
g(x)runs first — the inner function, applied to the raw input
f(g(x))runs second — the outer function, applied to \(g\)'s output, not to \(x\) directly

Order matters: \((f\circ g)(x) = f(g(x))\) is generally not the same as \((g\circ f)(x) = g(f(x))\). With the functions above, \(g(f(x)) = x^2+1\), a different expression from \((x+1)^2\) — check with \(x=2\): \(f(g(2))=f(3)=9\), but \(g(f(2))=g(4)=5\). Reading which function is "innermost" (applied first) versus "outermost" (applied last, to everything already computed) is exactly the skill needed to correctly read a nested formula later in this curriculum — a function of a function of a variable, several layers deep.

🧒 Explain like I'm 5

Composition is an assembly line: your input goes through one machine first, and whatever comes out the other end gets fed straight into a second machine. \(f(g(x))\) means "run it through \(g\) first, then run that result through \(f\)" — always start with the machine closest to \(x\), like unwrapping a present starting with the innermost layer of paper.

Inverse functions

The inverse of a function \(f\), written \(f^{-1}\), is the machine that exactly undoes \(f\): feed \(f\)'s output back into \(f^{-1}\), and you get the original input back. Not every function has an inverse (it needs to be one that never produces the same output from two different inputs), but where one exists:

\[ f^{-1}(f(x)) = x \qquad\text{and}\qquad f(f^{-1}(x)) = x \]
f⁻¹the inverse machine — note this is notation, not "1 divided by \(f\)"
f⁻¹(f(x)) = xapplying \(f\) then its inverse returns exactly the original input

To find an inverse algebraically: write \(y=f(x)\), swap \(x\) and \(y\), then rearrange to solve for \(y\) again. For \(f(x)=2x+3\): write \(y=2x+3\), swap to \(x=2y+3\), rearrange for \(y\): \(y = (x-3)/2\). So \(f^{-1}(x) = (x-3)/2\) — and indeed, subtracting 3 and dividing by 2 is exactly how you'd undo "multiply by 2, then add 3." Rearranging an equation and finding an inverse function are, underneath the notation, literally the same algebraic move.

🧒 Explain like I'm 5

An inverse is the "undo" button. If a machine turns 4 into 11, its inverse machine turns 11 back into 4. Finding an inverse is just figuring out, one step at a time, how to walk the original machine's steps backward — the exact same "undo it in reverse order" idea as rearranging an equation, just wearing different notation.

\(x, y\)Generic variables — an input (\(x\)) and an output or dependent quantity (\(y\)).
\(f, g\)Function names — labels for a specific input→output rule.
\(f(x)\)"\(f\) applied to \(x\)" — the output of function \(f\) given input \(x\). Not multiplication.
\(m\)Slope of a straight line — rise over run, \(\Delta y/\Delta x\).
\(c\)Intercept — the value of \(y\) when \(x=0\).
\(\Delta\)(delta) "change in" — \(\Delta x\) means the change in \(x\) between two points.

Worked example

Rearranging the compound-interest formula to solve for the rate

The compound-interest formula gives the future value \(FV\) of a present sum \(P\) invested for \(n\) periods at rate \(r\) per period:

\[ FV = P(1+r)^n \]

Suppose \(P = \$1{,}000\), \(n = 5\) years, and the investment grows to \(FV = \$1{,}276.28\). What annual rate \(r\) does that imply? Solve for \(r\) step by step — the same "undo the operations in reverse order" discipline from Section 2, just with a root and no simple division this time.

1

Isolate the \((1+r)^n\) term

Divide both sides by \(P\) to get the growth factor alone on one side:

\[ \frac{FV}{P} = (1+r)^n \]
2

Undo the power with a root

Raising both sides to the power \(1/n\) is the inverse operation of raising to the power \(n\) — it "undoes" the exponent, the same way dividing undoes multiplying:

\[ \left(\frac{FV}{P}\right)^{1/n} = 1+r \]
🧒 Explain like I'm 5

Raising something to the power \(1/n\) is just a fancier way of saying "take the \(n\)th root." You already know one version of this trick: a square root (\(x^{1/2}\)) undoes squaring. This step is the exact same undo-move, just stretched to work on any power, not only squaring.

3

Isolate \(r\)

Subtract 1 from both sides:

\[ r = \left(\frac{FV}{P}\right)^{1/n} - 1 \]
4

Plug in the numbers

\[ r = \left(\frac{1276.28}{1000}\right)^{1/5} - 1 = (1.27628)^{0.2} - 1 \approx 1.0500 - 1 = 0.0500 \]

So \(r \approx 5.00\%\) per year. Check it: \(1000 \times (1.05)^5 = 1000 \times 1.27628 = \$1{,}276.28\) — matches the given \(FV\) exactly.

Real-world trading scenario

Solving a leverage formula backwards for the required equity

A trader's position size (in units of the underlying) is set by leverage against their account equity:

\[ \text{position size} = \text{equity} \times \frac{\text{leverage}}{\text{price}} \]
equity
Account capital
The cash actually deposited — the thing being solved for here
leverage
Multiplier
e.g. 30:1 — how many units of exposure per unit of equity
price
Instrument price
Converts a notional dollar exposure into a unit count
🧒 Explain like I'm 5

Leverage means a broker lets you control more money than you actually put up. "20:1 leverage" means for every \$1 of your own cash, you're allowed to control \$20 worth of whatever you're trading. So the question below is really just: "I want to control \$12,000 worth, and I'm allowed to multiply my own money by 20 — how much of my own money do I actually need?" That's \$12,000 ÷ 20.

Say a trader wants exactly 10,000 units of exposure to an instrument trading at \$1.20, using 20:1 leverage. How much equity is required? Rearrange for \(\text{equity}\): multiply both sides by \(\text{price}\), then divide both sides by \(\text{leverage}\):

\[ \text{equity} = \frac{\text{position size} \times \text{price}}{\text{leverage}} = \frac{10{,}000 \times 1.20}{20} = \frac{12{,}000}{20} = \$600 \]

The trader needs \$600 of equity to support that position at that leverage and price. This is the same "isolate the variable" move as the worked example above, applied to a formula with three inputs instead of one rate — the algebra doesn't change just because the formula got longer.

Section 03

How practitioners actually use this

Nobody at a trading desk sits down to "do algebra" as a named activity — but every pricing model, every risk formula, and every sizing rule is a function, and using one in practice constantly means running it in a direction it wasn't originally written for. A model might be built to compute an expected price from a set of inputs; a trader instead has an observed market price and wants to know what input (a rate, an implied volatility, a required return) would have produced it. That's an inverse problem, and solving it is exactly the rearranging drilled on this page, just embedded in a more complicated formula. Quant and desk-analyst interviews frequently test precisely this skill directly — "given this formula, solve for this other variable" — because it's the daily mechanical work underneath far fancier-sounding tasks like calibration or implied-volatility surface construction.

Reading a chart's slope and concavity at a glance is equally constant: a steepening yield curve, an accelerating drawdown, a payoff diagram that bends favorably near a strike price are all, underneath the finance vocabulary, just "is this graph's slope increasing or decreasing, and in which direction." Practitioners build the habit of translating a plotted curve into slope-and-concavity language automatically, because so much of quantitative finance's vocabulary — convexity, duration, gamma — is that same idea renamed for a specific context.

⚠️
Common pitfalls

Where this goes wrong in practice

Doing an operation to only one side of an equation. The single most common algebra error: subtracting a term from the left side but forgetting to subtract it from the right too. The equation stops being true the instant the two sides are no longer treated identically.

Confusing a function's name with its output. \(f\) is the machine; \(f(x)\) is a specific output for a specific input. Writing "\(f = x^2\)" instead of "\(f(x) = x^2\)" blurs that distinction and gets confusing fast once composition and inverses show up.

Assuming every function has an inverse. \(f(x) = x^2\) over all real numbers does not have a clean inverse — both \(x=2\) and \(x=-2\) give \(f(x)=4\), so there's no way to tell, given only the output 4, which input produced it. (Restricting the domain to \(x \ge 0\) fixes this — a detail that matters more than it looks, and recurs whenever a later formula involves a square or a square root.)

Mixing up composition order. \(f(g(x))\) and \(g(f(x))\) are generally different expressions — always work from the innermost function outward, and don't assume a nested formula can be read in either order.

Section 04

Key Takeaways

✓An equation stays true if both sides get the same treatment. Solving for a variable is just repeatedly undoing operations, in reverse order, on both sides at once.
✓A function is a machine, not a solved value. \(f(x)\) means "apply the rule \(f\) to input \(x\)" — the \(x\) is a placeholder, not an unknown to solve for.
✓Domain and range bound what's possible. Domain is what a function can accept; range is what it can produce — both matter before trusting a formula's output.
✓Slope is constant on a line, changing on a curve. A changing slope is exactly what "curving" (convex/concave) means — the idea convexity later builds on directly.
✓Composition and inverses chain or undo functions. Order matters for composition; not every function has a clean inverse.
⚠Rearranging gets harder once roots and exponents are involved. The compound-interest example needed a fractional-power root, not just addition/subtraction — a habit worth building now, before formulas get longer.
Section 05

Self-test

Q1. Rearrange \(y = 3x - 7\) to solve for \(x\) in terms of \(y\).
Add 7 to both sides: \(y+7 = 3x\). Divide both sides by 3: \(x = (y+7)/3\). Check by substituting back: if \(x=(y+7)/3\), then \(3x-7 = 3\cdot(y+7)/3 - 7 = (y+7)-7 = y\) — confirms the rearrangement is correct.
Q2. Is \(y^2 = x\) a function of \(x\)? Why or why not?
No. A function must assign exactly one output to every input. For \(x=9\), both \(y=3\) and \(y=-3\) satisfy \(y^2=9\) — two valid outputs for one input, which breaks the definition. \(y=\sqrt{x}\) (taking only the non-negative root) is a genuine function; \(y^2=x\) on its own is not.
Q3. For \(f(x) = x^2\) and \(g(x) = x - 2\), compute \((f\circ g)(5)\) and \((g\circ f)(5)\). Are they equal?
\((f\circ g)(5) = f(g(5)) = f(3) = 9\). \((g\circ f)(5) = g(f(5)) = g(25) = 23\). They are not equal — composition is generally not commutative, so the order in which two functions are chained matters.
Q4. Does \(y = -2x^2 + 3\) curve up or down, and how do you know without plotting it?
It curves down (concave). The coefficient on \(x^2\) is \(a=-2\), which is negative — a negative leading coefficient on a quadratic means the parabola opens downward ("sheds water"), the reverse of the \(a>0\) case which opens upward. No plotting is needed; the sign of \(a\) alone determines the direction of curvature.
Q5. Find the inverse of \(f(x) = 5x - 10\), and verify it by computing \(f^{-1}(f(4))\).
Write \(y=5x-10\), swap \(x\) and \(y\): \(x = 5y-10\), then solve for \(y\): \(y = (x+10)/5\). So \(f^{-1}(x) = (x+10)/5\). Verify: \(f(4) = 5(4)-10 = 10\), and \(f^{-1}(10) = (10+10)/5 = 20/5 = 4\) — exactly the original input, as required of a genuine inverse.
