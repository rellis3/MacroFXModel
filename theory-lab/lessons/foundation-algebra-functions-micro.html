Section 01

An equation is a balance scale

Whatever you do to one side, you must do to the other — that's the entire rule.

2x + 3 = 11, balanced
Do the same thing to both pans and it stays level. Peel the equation apart one step at a time, below.
Solving it — one move at a time
Same rule, every time: subtract, then divide — evenly, on both sides — until x is alone.
Section 02

A function is an input → output machine

One input always produces exactly one output — never two.

f(x) = x², fed two different inputs
3 and −3 both go in — 9 always comes out. The machine only cares about the square, never the sign.
Section 03

Domain & range: what it can eat, what it can spit out

Domain is every input a function accepts without breaking. Range is every output it can actually produce.

Domain of f(x) = 1/x — every real number except one
Dividing by zero is undefined, so 0 is the one input this machine can't accept — every other real number is fair game.
Section 04

A straight line has one slope; a curve's slope keeps changing

Drag the slider — the blue line always tilts evenly. The purple curve doesn't.

Slope and curvature, live

The line rotates evenly no matter how you tilt it — a curve bends, meaning its own steepness is different at every point.
Section 05

Same algebra, on a trading desk

Rearranging a formula is a daily move — here it's solved backwards for the equity a trade needs.

equity = (position size × price) ÷ leverage
Same "isolate the variable" move as the balance-scale example — just applied to a formula with three inputs instead of one.
Section 06

Quick check

Q1. Rearrange y = 3x − 7 for x.
x = (y + 7) / 3 — add 7 to both sides, then divide both sides by 3.
Q2. Can f(x) = x² ever output a negative number?
No. Squaring any real number always gives zero or a positive result — negative outputs simply aren't in this machine's range.
Q3. 10,000 units at $1.20, 20:1 leverage — how much equity is needed?
$600 — (10,000 × 1.20) ÷ 20 = $600.
