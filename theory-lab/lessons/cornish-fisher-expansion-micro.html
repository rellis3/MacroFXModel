Cornish-Fisher Expansion — Nudging the Quantile, Not the Formula

The previous deep dive defined VaR as a quantile of the loss distribution and showed why coherent risk measures matter — but said nothing about how VaR actually gets computed day to day. The most common answer assumes returns are normally distributed, which real returns almost never are. This lesson covers the standard fix — an adjustment to the one number the Gaussian formula gets wrong — and the well-documented way that fix can itself misbehave.

Section 1

Same VaR this series already defined — just the one shortcut everyone actually uses to compute it.

VaR_α
μ

Mean return

The average return of the series — usually small and often set to zero for a clean daily VaR calculation.

σ

Standard deviation

How much the return series wobbles day to day — the plain, familiar volatility number.

α

Tail probability

0.05 for a 95%-confidence VaR, 0.01 for 99% — the slice of outcomes being called "the bad tail."

z_α

Standard normal quantile

Read straight off a normal table — z0.05 ≈ −1.645. This is the one number this whole lesson is about.

The prior lesson on Coherent Risk Measures defines VaR_p(L) as a quantile and deliberately assumes nothing about the loss distribution's shape. This formula is the popular shortcut for actually computing that quantile — and it only works exactly if returns really are normally distributed.
Section 2

Real returns don't look like the bell curve

Two extra shape facts the Gaussian formula throws away entirely.

Try it
S < 0
→
longer left tail
Skewness is the third standardized moment. S = 0 is symmetric, like a normal distribution. S < 0 — the common case for equity and FX returns — means a longer, fatter loss tail than gain tail: crashes run further than rallies do.
K > 0
→
fatter tails, both sides
Excess kurtosis is the fourth standardized moment minus 3 (a normal distribution's own kurtosis), so K = 0 means normal-tailed. K > 0 ("leptokurtic") means more extreme observations than a bell curve predicts, in both directions — the textbook "fat tails" of financial returns.

Daily FX, equity, and rates returns are typically both: negatively skewed and fat-tailed. Plugging only μ and σ into the Gaussian formula assumes S = 0 and K = 0 by default — silently discarding exactly the shape information that would tell you the tail is worse than "average-shape" implies.

Why this matters, not just aesthetically

A VaR number computed as if returns were symmetric and normal-tailed understates the loss threshold precisely where it matters most — the tail, which is the whole reason VaR gets computed in the first place.

Section 3

Same mean and spread, very different left tail

Both curves below share the same peak height. Only the shape differs — and only the shape is what the Gaussian formula can't see.

Hand-drawn, to scale in spirit only

The grey curve is the same mean, same spread — just reshaped to have a longer, slower-decaying left tail. A quantile drawn from the blue normal curve (the Gaussian z_α) sits noticeably short of where the grey curve's real tail actually begins. The Cornish-Fisher expansion is precisely the tool for moving that quantile mark to where the amber sliver says it belongs.

Section 4

Cornish & Fisher's fix: adjust z_α, not the formula

z_CF = z_α + (z_α²−1)S/6 + (z_α³−3z_α)K/24 − (2z_α³−5z_α)S²/36 — then z_CF replaces z_α, everywhere, in the exact same VaR formula.

z_α

The baseline

What you'd use if returns really were normal. Set S = 0 and K = 0 and every term below vanishes — z_CF collapses back to plain z_α.

S

Skew correction

(z_α²−1)S/6 minus (2z_α³−5z_α)S²/36. Pushes the quantile further into the tail when losses run more extreme than gains.

K

Kurtosis correction

(z_α³−3z_α)K/24. Pushes the quantile further out when the distribution has fatter tails than normal.

Think of a tailor who marks a hem 1.645 inches up from the floor because that's correct for a perfectly average, symmetric build. Cornish-Fisher is the tailor learning to nudge that mark using two measurements of this specific customer — how lopsided they are, and how much more extreme their proportions run — instead of assuming everyone is exactly average. Same tape measure, same formula; only the one number being fed into it moves.
Section 5

The same data, two different VaR numbers

A daily return series: μ = 0%, σ = 1.20%, skewness S = −0.5, excess kurtosis K = 3 — a realistic negative-skew, fat-tailed shape. Compute the 95%-confidence VaR (z_α = −1.645) both ways.

Try it
z_α = −1.645
→
VaR = 1.974%
−0% − (−1.645)(1.20%) = 1.974%. This assumes S = 0 and K = 0 — an "average-shape" return series that doesn't actually match the one being measured.
z_CF ≈ −1.722
→
VaR = 2.066%
Skew terms contribute about −0.137, the kurtosis term about +0.060, moving z_α = −1.645 to z_CF ≈ −1.722. −0% − (−1.722)(1.20%) = 2.066%.

2.066% vs. 1.974% — the Cornish-Fisher-adjusted VaR comes out roughly 4.7% larger than the plain Gaussian VaR, from the exact same μ and σ. The entire difference is the quantile shift z_α → z_CF; nothing else in the formula changed.

Section 7

Drag skewness far enough, and the fix breaks

Fixed at σ = 1.20%, excess kurtosis K = 1. Drag skewness from a realistic −0.5 toward an extreme −3.5 and watch the 99% bar.

Try it
Skewness SS = −0.50
A 99%-confidence VaR should never be smaller than a 95%-confidence one on the same distribution — a higher confidence level always means further into the tail.

Past roughly S ≈ −2.4 at this kurtosis, z_CF stops increasing monotonically with confidence — the "99% VaR" the formula reports actually falls below the "95% VaR" it reported a moment ago. That is not a rounding quirk; it's the polynomial correction overshooting itself.

Section 8

The irony: the fix for non-normality isn't always valid itself

The whole point of a quantile function is that it increases as the confidence level increases. For sufficiently extreme |S| and K, the Cornish-Fisher transform can violate exactly that property — producing an "adjusted VaR" that is not a valid quantile at all, just an artifact of the correction terms overshooting. This is formally characterized in the literature (Jaschke, 2002), not a hypothetical edge case.
What the previous slide's slider just demonstrated

Cornish-Fisher is a useful correction within a bounded region of (S, K) inputs — not a universal fix for non-normality. Outside that region, using the output "uncritically" (its own risk: treating the number as trustworthy just because a formula produced it) can silently hand a risk desk a nonsensical number.

✓

"More conservative" ≠ "more correct"

The worked example shows CF-VaR larger than Gaussian VaR — but the direction and size of the adjustment depend entirely on the sign and magnitude of the S and K fed in, not a built-in conservative bias.

📉

Higher-order moments are noisy

Skewness and especially kurtosis converge far more slowly than the mean or variance. A short return history can produce an S and K dominated by one or two extreme observations.

◎

Still just a quantile

Cornish-Fisher adjusts where the quantile sits — it does not turn VaR into an average-of-the-tail measure. Everything the prior lesson said about VaR's blind spot past the threshold still applies.

Section 9

A cheap upgrade, with a boundary you must respect

Where it earns its keep
  • Drop-in for an existing Gaussian VaR pipeline — only z_α → z_CF changes
  • No need to refit a whole new parametric distribution
  • Uses two sample statistics (S, K) that are already cheap to compute
  • A standard, documented option in commercial risk platforms
Where it breaks down
  • Non-monotonic past a bounded region of extreme (S, K) — see the slider above
  • Only as good as the sample S and K feeding it — noisy in short histories
  • No warning built into the formula itself when it has overshot
  • A local correction, not a substitute for genuine tail modeling at extremes

The difference isn't "trustworthy vs. untrustworthy" — it's knowing which side of the boundary a given (S, K) pair falls on before reporting the number to a risk committee as if it were unconditionally valid.

Section 10

Where this shows up on a desk

A short-volatility FX carry book earns small, steady gains most days, punctuated by sharp drawdowns when a funding currency spikes — the textbook negative-skew, fat-tailed shape. Reporting its VaR the plain Gaussian way is, in effect, pretending those returns look like a coin flip around a fair average — the opposite of the strategy's actual shape. Feeding the desk's own historical S and K into Cornish-Fisher gets a materially larger, more honest number for how bad a genuinely bad day could be, without building an entirely new distributional model.
Checked against this repo's actual code

This project's own backtest analytics already compute sample skewness and excess kurtosis (js/metricsCore.js) and feed them into a Probabilistic-Sharpe-style adjustment (minTrackRecordLength) — but the VaR/CVaR this repo actually reports (histVaR/histCVaR) is computed empirically, from the historical return quantile itself, not via the Cornish-Fisher quantile adjustment this lesson describes. The full lesson's own framing holds up: Cornish-Fisher is explained here as a technique, not a claim about what this codebase runs.

Section 11

Check yourself

Nothing is scored beyond this device. The explanation is the useful part.

Question 1

What does the Cornish-Fisher expansion actually change in the VaR formula?

−μ − zσ stays exactly the same. z_CF is simply substituted for z_α inside it — that's the entire adjustment.
Question 2

Why does z_CF equal z_α exactly when a return series is perfectly normal?

Every correction term is multiplied by S, K, or S² — with both S and K at zero, all three vanish and z_CF reduces to z_α with nothing added.
Question 3

In the worked example (S=−0.5, K=3), why is the Cornish-Fisher VaR larger than the Gaussian VaR?

z_CF ≈ −1.722 vs. z_α = −1.645. The VaR formula subtracts z times σ, so a more negative z adds more to the result — 2.066% vs. 1.974%.
Question 4

What, precisely, goes wrong with Cornish-Fisher at extreme skew/kurtosis?

A genuine quantile function must increase with confidence. Past a bounded region of (S,K), Cornish-Fisher can violate that — a documented failure mode (Jaschke, 2002), not a rounding artifact.
Question 5

A colleague says "Cornish-Fisher VaR is always more conservative, so it's always the safer number." What's wrong?

A badly estimated or genuinely positively-skewed, thin-tailed series can push z_CF toward a SMALLER VaR than the Gaussian number. The adjustment is data-dependent, not a built-in safety margin.
Section 12

What to carry forward

01

Gaussian VaR assumes S=0, K=0 — an assumption real financial returns almost never satisfy, usually failing in the worst direction (negative skew, fat tails).

02

Cornish-Fisher adjusts one number, z_α → z_CF, using the return series's own sample skewness and kurtosis — the rest of the VaR formula is untouched.

03

For a realistic S=−0.5, K=3 series, CF-adjusted 95% VaR comes out about 4.7% larger than plain Gaussian VaR — 2.066% vs. 1.974%, from identical μ and σ.

04

It's a cheap, drop-in upgrade to an existing Gaussian pipeline — no distribution refit required, just two already-computable sample moments.

05

Past a bounded region of extreme (S, K), the expansion becomes non-monotonic — a documented failure (Jaschke, 2002), not a hypothetical edge case.

06

It's only as reliable as the S and K estimated from your sample — higher-order moments are noisy, especially over short histories.

What this now lets you do

Take an existing Gaussian VaR number and, for the cost of two sample statistics you likely already compute, produce a more honest tail-risk estimate that reflects the actual shape of your returns — while knowing exactly which (S, K) region to stay inside of, and recognising the non-monotonicity warning sign the moment a confidence-level ordering looks backwards.
