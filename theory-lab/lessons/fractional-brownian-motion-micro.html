Fractional Brownian Motion, Long Memory Made Precise

The Hurst-exponent lesson measured "persistence" with a slope fit to rescaled ranges — useful, but model-free: a bare number with nothing behind it. This deck gives H a real generating process, fractional Brownian motion, plus its discrete-time cousin ARFIMA, and uses both to turn "long memory" from a loose adjective into a formally checkable property that no ordinary AR/ARMA model — however many lags it's given — can ever possess.

The whole idea
🎧 Listen · the four-minute version

A trader and a quant talk the lesson through. No symbols, just the idea and one worked number, so it works on a walk or a commute.

Last lesson I measured a Hurst exponent on a price series. It came out at zero point eight five. What does that number actually mean?

On its own, not much. It is a slope from a fit. This lesson gives it a model behind it: fractional Brownian motion.

How is that different from a normal random walk?

A normal random walk has no memory. Every step is a fresh coin flip. Fractional Brownian motion has a memory dial built in, and the Hurst number is the dial. At one half, it is exactly the ordinary random walk again.

And above one half?

Persistent. A move up makes the next move a little more likely to be up. Below one half it is the opposite: moves tend to reverse.

But an ordinary autoregressive model has persistence too.

It does, and that is the key distinction. In an autoregressive model the memory fades exponentially. With a coefficient of zero point seven, the correlation is gone by lag ten. Add all the correlations up and you get a finite number, about two point three.

And long memory?

It fades as a power law. Still around zero point three at lag fifty. Add the correlations up and the total never stops growing. That is the strict definition of long memory, and no autoregressive model can produce it, however many lags you give it.

So what do I fit to real data?

A model called ARFIMA. It differences the data by a fraction instead of a whole step. The fraction is the Hurst number minus one half. Your zero point eight five becomes zero point three five.

Does this mean returns are predictable?

Mostly not. Mandelbrot pushed long memory into finance in the sixties. But Andrew Lo's 1991 test, which allows for ordinary short-term dependence, found little of it in stock returns. The memory turned out to be in volatility. Ding, Granger and Engle showed in 1993 that absolute returns stay correlated over very long lags.

So that is where it pays.

That is where it is used: long-memory volatility models such as fractionally integrated GARCH, and since 2014, rough volatility, which finds a Hurst number near zero point one for log-volatility.

Any trap?

Two. Several calm and wild regimes stitched together can look exactly like long memory, so check for breaks first. And a better fit is a better description, not a trading edge, until it passes an honest out-of-sample test.

One line?

Long memory means correlations that fade too slowly ever to add up; it lives in volatility far more than in returns.

How it reached trading

Mandelbrot brought long memory to price data in the 1960s, and early R/S studies seemed to find it in stock returns. Lo's 1991 modified R/S test, robust to short-term dependence, found little.

The memory was in volatility: Ding, Granger & Engle (1993) found absolute returns autocorrelated over very long lags, leading to FIGARCH and HAR. "Volatility is rough" (Gatheral, Jaisson & Rosenbaum, 2014/2018) put log-volatility at H near 0.1.

Section 2

A measurement in search of a machine

The Hurst exponent & variance-ratio lesson estimated H straight from historical data, with no commitment to what process produced it. Fractional Brownian motion is that missing process.

R/S & variance ratio — model-free

Estimate a single number, H, purely from how a real path has wandered. A genuine strength — no belief in a specific model required — but it leaves basic questions unanswered: does the correlation between today and 50 days out ever truly vanish, or just get small? Is "persistent" the same thing as "long memory"? No crisp answer without a model.

Fractional Brownian motion — a generating process

A continuous-time Gaussian process built so H isn't fit after the fact — it's a parameter of the process's exact covariance structure. Every question above gets a precise, derivable answer, and the R/S statistic turns out to be exactly the empirical test for this process's existence.

Ordinary Brownian motion is amnesiac — every increment is a fresh coin flip, indifferent to the past. fBm keeps the same jagged, continuous look but bakes in a controllable amount of memory: a single dial, H, between 0 and 1, built directly into the covariance formula this whole lesson is a consequence of.
Section 3

One formula defines the whole process

Fractional Brownian motion BH(t) is the centered Gaussian process with BH(0)=0 and this covariance, for s,t ≥ 0 and H ∈ (0,1).

Cov(BH(s), BH(t))
=
½·( |s|2H + |t|2H − |t−s|2H )
Σ

The whole process

Everything about fBm — its variance, its increment correlations, whether it counts as "long memory" — is a consequence of this one covariance formula. Nothing else is assumed.

H

The Hurst index

A parameter of the process itself, not a slope estimated after the fact — the same H the previous lesson's R/S regression was always implicitly trying to recover.

Δ

The memory term

|t−s|2H cancels exactly at H = 0.5. Everywhere else it survives and encodes real, non-zero correlation between the process's values.

Set H = 0.5, so 2H = 1, and take 0 ≤ s ≤ t: the formula becomes ½(s + t − (t−s)) = ½(2s) = s = min(s,t) — exactly ordinary Brownian motion's covariance. That cancellation is exact, algebraic, and the defining check any candidate fBm formula must pass: at H = 0.5 the general case reduces, term for term, to the special case everyone already knows. A second consequence of the same formula: Var(BH(t) − BH(s)) = |t−s|2H, so an increment's standard deviation over a span of length n scales as nH — precisely the power law R/S analysis was built to detect.

Section 5

How H reshapes the walk

Same starting point, three values of H. Only the middle one is a true, memoryless random walk.

Try it
H = 0.3. Increments are negatively correlated — an up-move makes a down-move more likely next. Var(increment) scales as n0.3, slower than √n, so the path is confined near its starting level. Real, useful mean-reversion structure — but, as Section 7 shows, technically short memory.
H = 0.5. Non-overlapping increments are exactly independent — the covariance formula's cross-terms cancel completely. No persistence, no anti-persistence, nothing to model: this is ordinary Brownian motion, Var(increment) ∝ n1, the baseline every other H is measured against.
H = 0.8. Increments are positively correlated and, critically, that correlation decays as a power law in the lag — not exponentially. Var(increment) scales as n1.6, faster than √n: fewer, longer, smoother directional runs, with real correlation surviving to far longer lags than any AR(1)-style process could produce.

Section 7

"Long memory" has an exact definition

Not "somewhat persistent." A stationary process has long memory exactly when its autocovariance γ(k) is not absolutely summable: Σ|γ(k)| = ∞. For fractional Gaussian noise (fBm's increments), γ(k) behaves like H(2H−1)·k2H−2 for large k.

∞

H > 0.5 — the sum diverges

Exponent 2H−2 > −1, so Σ k2H−2 diverges. This is genuine long memory in the strict, formal sense — not a matter of degree.

Σ

H < 0.5 — the sum converges

Exponent 2H−2 < −1: the sum converges absolutely, even though the correlations are real and negative. Genuine mean-reverting structure — but technically short memory, not long memory with a minus sign.

0

H = 0.5 — trivial

γ(k) = 0 for every k ≠ 0. The sum is trivially finite because there's nothing there to sum.

The mistake worth avoiding

Calling H < 0.5 "long memory" is a common looseness. It's real, useful, negatively-correlated structure — but by the strict Σ|γ(k)| definition it's short memory, formally the same category as an AR(1) process, just with a different sign on the correlation.

Section 8

The crux: no ARMA model ever gets there

Exponential decay vs. power-law decay isn't a matter of degree — it's a different category of object.

Any finite-order ARMA — short memory
  • Autocorrelation decays geometrically, ρ(k) = φk
  • Σ|φ|k = 1/(1−|φ|), finite for any |φ| < 1
  • More lags change the rate of decay, never its summable character
  • By lag 10–15, correlation is numerically indistinguishable from zero
fBm / fractional Gaussian noise — long memory (H>0.5)
  • Autocorrelation decays as a power law, ρ(k) ∝ k2H−2
  • Σ k2H−2 = ∞ whenever H ≥ 0.5
  • Needs a structurally different process, not a bigger version of ARMA
  • Can still show real correlation at lag 50–60 and beyond

Section 9

ARFIMA — fBm's spreadsheet-friendly cousin

fBm is continuous-time, awkward to fit to daily bars directly. ARFIMA generalizes ordinary ARIMA's integer differencing d to any real number, via d = H − 0.5.

+

d ∈ (0, 0.5) ⇔ H ∈ (0.5, 1)

Genuine long memory. A fractional differencing pass — less than one whole integer difference — is enough to induce stationarity.

0

d = 0 ⇔ H = 0.5

No fractional differencing needed at all — collapses to an ordinary stationary ARMA model, the econometric mirror of fBm's own reduction to Brownian motion.

−

d ∈ (−0.5, 0) ⇔ H ∈ (0, 0.5)

The anti-persistent, short-memory-but-negatively-correlated case — a legitimate, if less commonly discussed, negative fractional order.

The payoff: ARFIMA fits the slow, power-law-decaying autocorrelation from Section 7–8 using ordinary discrete-time estimation (maximum likelihood, or the Geweke–Porter-Hudak semiparametric estimator) — an econometrician's tool for a physicist's process, with no continuous-time machinery required.

A researcher who estimates H ≈ 0.85 on a volatility series is, via d = H − 0.5, looking at d ≈ 0.35 in ARFIMA terms — comfortably inside the stationary-and-invertible range d ∈ (−0.5, 0.5). Run the other direction just as easily: an ARFIMA fit reporting d̂ = 0.4 is reporting H ≈ 0.9, very strong persistence, in exactly the language the Hurst lesson's R/S regression would have used.

Section 11

Where this reasoning goes wrong

⏳

fBm itself isn't stationary

Var[BH(t)] = t2H grows with t. Only its increments — fractional Gaussian noise — have a well-defined ACF worth discussing. Running memory diagnostics on levels instead of increments is the same mistake the stationarity lesson warns about with raw price levels.

⚡

Structural breaks can fake long memory

Several genuinely short-memory regimes stitched together (calm-market AR(1) alternating with crisis-period AR(1) at a different level) can show an aggregate ACF that decays visually just as slowly as true long memory — a well-documented confound to rule out before reaching for ARFIMA.

±

d̂ carries real estimation uncertainty

Maximum likelihood, GPH log-periodogram regression, and other estimators can disagree meaningfully on the same finite sample — a single reported d̂ deserves the same skepticism as a single point estimate of H from R/S analysis.

✓

A good in-sample fit isn't edge

ARFIMA/FIGARCH out-fitting a misspecified GARCH is a real methodological upgrade — a better-specified model of volatility's dependence structure. It is not, by itself, evidence that trading its longer-horizon forecast makes money without a costed, out-of-sample test.

Section 12

Check yourself

Nothing is scored beyond this device. The explanation is the useful part.

Question 1

At H = 0.5, the general fBm covariance formula algebraically reduces to what?

½(s+t−(t−s)) = ½(2s) = s = min(s,t) for 0≤s≤t — the exact, algebraic check any candidate fBm formula must pass.
Question 2

What is the precise formal definition of "long memory"?

Long memory is categorical, not a matter of degree: a stationary process has it exactly when Σ|γ(k)| = ∞. Every finite-order ARMA process's geometric decay always sums to a finite value, so none of them can ever qualify.
Question 3

Is H < 0.5 (anti-persistent) formally "long memory"?

For H<0.5 the exponent 2H−2 < −1, so Σk^(2H−2) converges absolutely. Real, negatively-correlated, mean-reverting structure — but a formally different, short-memory category from H>0.5.
Question 4

ARFIMA reports d̂ = 0. What does that correspond to in H terms, and what model does it collapse to?

d = H − 0.5, so d=0 means H=0.5: no fractional differencing needed, and the model is just an ordinary stationary ARMA process — the discrete-time mirror of fBm's own reduction to Brownian motion.
Question 5

In this repo today, does featureHurst (built on computeHurst's R/S analysis) vote on live trade entries?

Your call
Scenario drill · an illustrative research week

The volatility residual that will not die

You model a currency pair's realized volatility with GARCH(1,1). The fit looks fine at short lags, but the residual autocorrelation is still small and clearly positive at lags of 60 trading days and beyond, well past what the GARCH persistence can explain. What is your next step?

  1. Add more lags: move to a higher-order GARCH or ARMA until the residuals look clean.
    More lags only change the rate of an exponential decay; they never make it a power law. Any finite-order model's correlations still add up to a finite total, so this cannot fix true long memory. You would overfit and still miss it.
  2. Check for structural breaks or regime shifts first; if the slow decay survives that, fit a long-memory model such as ARFIMA or FIGARCH and validate it out of sample.
    Slow decay can be faked by stitched-together regimes, so rule that out first. If it is real, the right fix is a different kind of process, not a bigger one, and any longer-horizon forecast still has to earn trust out of sample.
  3. Fit ARFIMA straight away. The fitted d comes out near 0.35, so H is about 0.85: trust the longer-horizon forecasts.
    Probably the right model family, but you skipped two checks: regime breaks can mimic long memory, and a better in-sample fit is not yet evidence that the longer forecasts make money.
  4. Conclude that the currency's returns are predictable over two-month horizons and trade the direction.
    The memory is in volatility, not in the direction of returns. Lo's 1991 test found little long memory in returns once ordinary short-term dependence is allowed for.

What happens. This is an illustrative situation based on the lesson's own scenario, not a dated episode. The pattern itself is well documented: absolute returns and realized volatility stay correlated over very long lags (Ding, Granger & Engle, 1993), which is why long-memory volatility models such as FIGARCH were built. Whether trading on them pays is a separate, out-of-sample question.

Section 13

What to carry forward

01

fBm gives H a real generating process — a Gaussian process defined entirely by Cov(BH(s),BH(t)) = ½(|s|^2H+|t|^2H−|t−s|^2H), which reduces exactly to ordinary Brownian motion, min(s,t), at H=0.5.

02

H controls path character continuously — H=0.5 amnesiac random walk, H>0.5 persistent/trending increments, H<0.5 anti-persistent/mean-reverting increments — the same fade/follow split the Hurst lesson introduced empirically, now with a formal source.

03

"Long memory" is a precise, checkable property — Σ|γ(k)|=∞ — not a vague "somewhat persistent." It holds for fractional Gaussian noise exactly when H≥0.5; H<0.5 is real correlation but technically short memory.

04

No finite-order ARMA model can ever have true long memory — exponential decay is always absolutely summable, however many lags are added. Only a power-law-decaying process like fBm/fGn crosses that line.

05

ARFIMA is the discrete-time tool practitioners actually fit — fractional differencing order d=H−0.5, so d∈(0,0.5) is genuine long memory, fit with ordinary econometric tools (MLE, GPH) and no continuous-time machinery required.

06

In this repo today, computeHurst/featureHurst exist and still run for research/benchmarking, but were dropped from the live conviction score on 2026-07-25; fBm and ARFIMA remain background theory, not implemented in any live forecaster.

07

Long memory reached finance through Mandelbrot, but Lo (1991) found little in returns; it lives in volatility, which is where FIGARCH, HAR and rough-volatility models use it.

What this now lets you do

Read H as a parameter of an actual generating process instead of a bare regression slope. Tell genuine long memory apart from a bigger, more-heavily-lagged AR/ARMA model dressed up to look persistent. Recognize when a residual ACF that refuses to decay past lag 40–60 is the empirical signature calling for ARFIMA or FIGARCH — while remembering, per this repo's own history with featureHurst, that a mathematically sound diagnostic still has to earn its place with real out-of-sample evidence.
