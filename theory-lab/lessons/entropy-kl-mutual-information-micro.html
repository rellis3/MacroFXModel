Entropy, KL Divergence & Mutual Information, Measured in Bits

Correlation only ever answers one narrow question: is there a straight-line relationship? Two variables can be locked together by an unmistakable, perfectly predictable rule and still show a correlation of exactly zero, simply because the rule isn't linear. This deck builds the machinery — entropy, KL divergence, and mutual information — that measures how much two variables actually tell each other, in bits, whether or not that relationship is a straight line at all.

Section 1

Correlation only sees straight lines

Two very different tools for the same question: "does knowing one variable tell me anything about the other?"

Correlation
  • Measures only linear (straight-line) association
  • Can be exactly zero even when two variables are perfectly, deterministically related — if the relationship curves, cycles, or is symmetric around a point
  • Cheap to compute, but silently blind to an entire category of real structure
Mutual information
  • Measures how much knowing one variable reduces uncertainty about the other — in any shape at all
  • Built directly from entropy and KL divergence, defined below
  • Zero exactly when the variables are truly independent — linear structure is just one special case it catches
A regression-only view of the world reports "no relationship" in exactly the cases where the relationship is real but curved, cyclical, or threshold-based — precisely the kind of structure that shows up in volatility responding to the size of a move rather than its sign. This deck builds the tool that catches it.
Section 2

Entropy: the price of not knowing yet

Shannon entropy H(X) = −Σ p(x)·log₂p(x) — a single number for "how surprised will I be, on average, before I find out?"

?

One outcome's surprise

−log₂p(x) — a rare outcome (p small) is very surprising; a near-certain one is barely surprising; a truly certain one (p=1) carries exactly zero surprise.

Σ

Entropy is the average

Weight each outcome's surprise by how often it actually happens, and sum. That expected surprise, in bits, is H(X).

▲

Maximized at "anything could happen"

When every outcome is equally likely, you have genuinely no basis for predicting the result — entropy is as large as it can get.

0

Zero at "already knew it"

One outcome with probability 1 and everything else impossible carries zero average surprise — there is nothing left to learn.

Using log base 2 makes the unit a bit — a fair coin flip carries exactly 1 bit of entropy, the most uncertainty a single yes/no outcome can hold. That's the benchmark the next slide's curve is built around.

Section 5

KL divergence: the cost of the wrong model

DKL(P‖Q) = Σ p(x)·log₂(p(x)/q(x)) — the extra bits wasted describing data from the true distribution P using a model Q instead.

Same two coins, both directions
DKL(P‖Q) = 0.919 bits
≠
DKL(Q‖P) = 2.329 bits
P = (0.99, 0.01), a coin that lands heads 99% of the time. Q = (0.5, 0.5), a naive fair-coin model. Swapping which distribution is "truth" and which is "model" changes the answer by roughly 2.5× — with the exact same pair of coins.

DKL(P‖Q) is always ≥ 0, with equality only when P = Q exactly (Gibbs' inequality, a short consequence of the concavity of log). That much behaves like a distance. But a real distance metric must also be symmetric and satisfy a triangle inequality — KL divergence satisfies neither.

Why "divergence," not "distance"

A code built assuming a 99%-biased coin spends almost no bits preparing for the "wrong" outcome, because it has written that outcome off as nearly impossible. When reality is actually a fair coin and that outcome shows up half the time, the mismatch is expensive — far more expensive than the reverse mistake of mildly under-preparing for something that turns out to be common. That asymmetry is the same reason underestimating tail risk is structurally more costly than overestimating it.

Section 7

Mutual information: built from both

The two-variable version of the KL question: how different is the real joint distribution from what it would look like if X and Y were independent?

The definition
P(X,Y) — the real joint
KL divergence between them
P(X)·P(Y) — if independent
I(X;Y) = DKL(P(X,Y) ‖ P(X)P(Y)). If X and Y really are independent, these two distributions are identical and I(X;Y) = 0. The more the real joint diverges from that independence benchmark, the larger I(X;Y) gets.

Because it's a KL divergence, I(X;Y) ≥ 0 always. Unlike KL divergence itself, mutual information is symmetric — I(X;Y) = I(Y;X) — because swapping X and Y leaves both P(X,Y) and P(X)P(Y) unchanged. It also has an equivalent, more intuitive form: I(X;Y) = H(X) − H(X|Y), "how much your uncertainty about X shrank once you learned Y."

This is the Y=X² worked example, proved on the next two slides. Y's circle sits entirely inside X's because H(Y|X)=0 — Y is a deterministic function of X, so nothing about Y is left unexplained.

Section 9

The Y = X² proof, in numbers

X takes values {−2,−1,0,1,2}, each with probability ⅕. Y = X² exactly — deterministic, so every number below is exact and checkable by hand.

0

Correlation(X, Y) = 0

Cov(X,Y) = E[X³] − E[X]E[Y] = E[X³] = 0 by symmetry — every odd power of X cancels around zero. Not "small." Exactly zero.

H

H(X) = log₂5 ≈ 2.322 bits

X is uniform over 5 equally likely values — maximum possible entropy for 5 outcomes.

H

H(X|Y) = 0.8 bits

Given Y=0, X=0 for certain (0 bits left). Given Y=1 or Y=4, X's sign is a coin flip (1 bit left). Averaged: ⅕(0)+⅖(1)+⅖(1) = 0.8.

I

I(X;Y) = 2.322 − 0.8 = 1.522 bits

Cross-checked the other way too: I(X;Y) = H(Y) − H(Y|X) = 1.522 − 0 = 1.522 bits. Both routes agree exactly.

This is not a subtle statistical artifact — it is the defining example of why "uncorrelated" must never be read as "unrelated." Mutual information is the tool that tells the two apart.
Section 10

Where practitioners actually use this

🎯

Cross-entropy loss

Training a classifier by minimizing cross-entropy is, up to a constant, exactly minimizing DKL(Pdata‖Qmodel).

🔍

Mutual-information feature ranking

Rank candidate predictors by I(Xᵢ;Y) instead of correlation, precisely to avoid discarding a genuinely predictive but nonlinear feature.

📦

Shannon's source coding theorem

Entropy is the hard floor on lossless compression — you cannot, on average, encode a source in fewer bits than its own entropy.

Section 12

Where this goes wrong in practice

⚠

Zero probability, undefined KL divergence

If q(x)=0 where p(x)>0, DKL(P‖Q) is technically infinite. A model with a hard zero anywhere in its support needs smoothing before KL against real data is computable at all.

↔

Reporting KL without a direction

DKL(P‖Q) and DKL(Q‖P) can differ by a large factor — quoting "the KL divergence between P and Q" without specifying direction is ambiguous.

📉

Mutual information needs a lot of data

Estimating I(X;Y) from a finite, noisy, continuous sample requires binning or kernel density estimation — both introduce bias, and a naive estimator can report spuriously large MI purely from overfitting a small sample.

🛑

Dependence is not the same as edge

A provably nonzero I(X;Y) says two variables aren't independent — nothing more. It does not say the relationship is strong, stable, or simple enough to trade on.

Section 13

Check yourself

Nothing is scored beyond this device. The explanation is the useful part.

Question 1

What is the Shannon entropy of a coin that always lands heads?

One outcome has probability 1 and carries zero surprise; every other outcome has probability 0 and contributes nothing to the sum. Expected surprise collapses to exactly zero — there's nothing left to learn.
Question 2

Is DKL(P‖Q) generally equal to DKL(Q‖P)?

Swapping which distribution is "truth" and which is "model" changes what mistake you're paying for. The worked coin example shows a roughly 2.5× gap between the two directions, using the exact same pair of coins.
Question 3

Can DKL(P‖Q) ever be negative?

Gibbs' inequality (a short application of Jensen's inequality on the concavity of log) proves D_KL(P‖Q) ≥ 0 always, with equality exactly when P = Q.
Question 4

Mutual information I(X;Y) is defined as which KL divergence?

I(X;Y) = D_KL(P(X,Y) ‖ P(X)P(Y)) — how far the actual joint distribution sits from what it would look like if X and Y were independent.
Question 5

For X symmetric around 0 and Y = X², what is the Pearson correlation between X and Y?

Cov(X,Y) = E[X³] = 0 by symmetry — every odd power of X cancels around zero. Correlation is exactly zero, yet mutual information comes out to 1.522 bits, clearly positive, because Y is a deterministic function of X.
Section 14

What to carry forward

01

Entropy H(X) = −Σp(x)log₂p(x) measures expected surprise in bits — 1 bit at its peak for a fair coin, falling to 0 bits for a certain outcome.

02

KL divergence DKL(P‖Q) measures the extra bits wasted describing data from P using model Q — always ≥ 0 (Gibbs' inequality), zero only when P = Q.

03

KL divergence is not symmetric — DKL(P‖Q) ≠ DKL(Q‖P) in general, so it's not a true distance metric, whatever it superficially resembles.

04

Mutual information I(X;Y) = DKL(P(X,Y)‖P(X)P(Y)) = H(X) − H(X|Y) — built directly from entropy and KL divergence.

05

Unlike KL divergence, mutual information IS symmetric (I(X;Y) = I(Y;X)) and always ≥ 0, zero exactly when X and Y are independent.

06

Correlation only catches straight lines and can be exactly zero even for a perfectly deterministic nonlinear relationship (Y=X²) — mutual information catches this because it makes no linearity assumption at all.
