Every line here was written down as a claim, pre-registered, then run against this desk's own data with paired controls — the same method whether the idea came from an educator, a newsletter, or the page itself. A ✓ validated finding is about range, never direction. A ∅ null is a relationship that was tested and did nothing — the brief is told to say so when it touches one. A ~ base rate is a description with its odds. A ◌ underpowered test could only have found an effect far larger than a realistic one: it rules out a big effect and says nothing about a small one. Each finding accumulates a forward record from the Desk Watch: every time it fired, and what the next five sessions actually did.
