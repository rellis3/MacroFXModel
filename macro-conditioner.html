Macro-Regime Conditioner

The honest question — not "fade here." Risk-off is also high-VIX is also high-σ, which the forecast band already prices. So this holds forecast σ fixed (tercile bucket) and asks: does macroCore's VIX+HY risk regime still move the day's character within a bucket? Flat within each σ bucket → macro is redundant with σ (the expected null). Separates → a real incremental state signal. Character = expansion rate (realized H-L > forecast 75th) and day-efficiency. FX majors, causal, IS/OOS split. This is a dispersion/state read that would feed sizing / target-width / posture — never a directional entry.

Pre-registered read: regime is INCREMENTAL only if ≥2 of 3 σ buckets show a RISK_OFF − RISK_ON spread with the same sign IS & OOS, |OOS| ≥ min-spread, each cell ≥ min-n. Otherwise the verdict is REDUNDANT_OR_NULL — σ already carries it. A null here is a clean result, not a failure.
