Forecaster System — built layer by layer from the lessons

A systematic build following the "Forecaster Portfolio" case study (3 of 17 lessons so far). Each layer has one job, is tested against its own standard, reports uncertainty, and logs every variant tried. New versions run side by side with the live system; nothing live changes until it is chosen. Plan and rules: plans/FORECASTER_SYSTEM_BLUEPRINT.md. Updated with every lesson. The daily output of the built layers: Forecaster Sheet.

The seven layers

1

Data built

Are the prices, sessions and sources correct and consistent?
One definition of a session, a daily bar and a realised value; sources per instrument; automated integrity report. Faults found and logged: UTC-day bars with Sunday stubs, Yahoo vs OANDA for indices, late session audits (fixed), signed open-to-close, local data 46 days stale.
plans/DATA_SPEC.md · scripts/data_integrity.mjs
2

Measurement defined

What is everything scored against?
London-day open→high, open→low, high−low and |open−close|, as % of the London-midnight open; intraday path from 1-minute bars.
3

Volatility forecast HAR chosen · live shadow

How far is price likely to travel today? (p50 / p75 / p90 lines)
The live ladder is right on average but tilts with the regime (quiet days pass p75 ~30%, busy ~20%). HAR-log σ flattens it (29% → 26%) and is sharper (IC 0.38 vs 0.29); the gap is smaller than first reported once regimes are bucketed neutrally, and HAR vs the IV-adjusted ladder cannot be separated. Frozen in the lockbox.
HAR Shadow (live) · forge/LADDER_CALIBRATION_PREREG.md
4

Path map done

How does price behave around those lines?
Real lines race exactly like control lines at other distances in all 314 conditions: no fade or continuation at the lines. What changes is time left: a line touched in the morning is the day's extreme 23% of the time, after 20:00 74%.
Path Map · forge/PATH_MAP_SPEC.md
5

Remaining travel near-pass · live shadow

From here, with the time left, how far can price still go?
Per-hour multipliers of σ (R3): calibrated across the day and regimes (miss 1.6pp) except 21:00 downside; fails the frozen rule by 0.1pp. Live on 16 sessions: up 53/24/9%, down 51/26/11% vs 50/25/10. More range used so far means more travel to come.
HAR Shadow (layer 5 section) · forge/REMAINING_TRAVEL_PREREG.md
6

Confidence small skill · calibration fail

How likely is layer 5's call to be right today — should we act at all?
Calibrated boosting beats layer 5's flat rates by 1.5–2.1% (Brier, holds out of sample) but misses calibration by 0.4pp. Carried by time of day and volatility so far; most useful late in the session.
forge/CONFIDENCE_PREREG.md
7

Sizing and risk sizing + stop map done

How much to hold, where stops go, what a stop really costs.
Sizing by any forecast σ halves the swing in risk at the same return (which σ hardly matters). Stops fill clean within the week (p99 1.0R) but not over weekends (p99 2.1R, 13% gap-through), on release minutes (1.6R), overnight (1.3R), tier-1 days or indices.
forge/VOL_TARGET_PREREG.md · forge/STOP_RISK_PREREG.md

How each new lesson is absorbed

  • Transcribe it word for word into education/forecaster-portfolio-case-study/.
  • Map what it adds to the layer(s) it touches.
  • Write each new instruction as a dated amendment to that layer's pre-registration — before anything runs.
  • Re-run the affected layers, record the results in the same file, update this page.

Shared statistics (Sharpe standard error, loss probability by horizon, bootstrap paths, deflated Sharpe, clustered errors, the replication rule): forge/evaltools.py, tested against Lesson 1's own numbers.
